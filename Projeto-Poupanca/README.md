# 💰 Projeto Poupança

Aplicativo mobile desenvolvido em **Android Studio** como projeto acadêmico, com foco na criação de uma interface para uma aplicação de poupança.

## 📌 Sobre o projeto

O **Projeto Poupança** foi desenvolvido durante a graduação em **Análise e Desenvolvimento de Sistemas (ADS)** com o objetivo de praticar conceitos de desenvolvimento de aplicações Android.

A aplicação possui uma interface voltada para o tema de poupança, utilizando elementos visuais e componentes de interação para criar uma experiência simples e organizada para o usuário.

O projeto também possibilitou praticar a criação de layouts, organização dos elementos da tela e desenvolvimento da interface utilizando **Java e XML**.

## 🎯 Objetivo

Desenvolver uma aplicação Android simples relacionada ao tema de poupança, colocando em prática conhecimentos de criação de interfaces, organização visual e interação com o usuário.

O projeto também teve como objetivo aprimorar a familiaridade com o **Android Studio** e com o desenvolvimento de layouts utilizando XML.

## ⚙️ Funcionalidades

- 💰 Interface relacionada ao tema de poupança
- 🔢 Entrada e visualização de valores
- 🐷 Elementos visuais relacionados ao tema
- 🔘 Botões de interação
- 📱 Interface desenvolvida para dispositivos Android
- 🎨 Organização dos componentes da tela

## 🎨 Interface

A interface foi desenvolvida buscando manter uma aparência simples, organizada e fácil de utilizar.

O projeto utiliza elementos visuais relacionados ao tema financeiro, incluindo uma identidade visual própria e componentes organizados para facilitar a interação do usuário.

Entre os principais elementos utilizados estão:

- 🐷 Logo/ilustração relacionada à poupança
- 💰 Título da aplicação
- 🔢 Campos relacionados aos valores
- 🔘 Botões de interação
- 📱 Componentes de interface Android
