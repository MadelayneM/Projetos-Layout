# 🍽️ Conta Restaurante

Aplicativo mobile desenvolvido em **Android Studio** como projeto acadêmico, com foco na criação de uma interface para uma aplicação de restaurante.

## 📌 Sobre o projeto

O **Conta Restaurante** foi desenvolvido durante a graduação em **Análise e Desenvolvimento de Sistemas (ADS)** com o objetivo de praticar conceitos de desenvolvimento de aplicações Android.

A aplicação apresenta uma interface inspirada em um restaurante, permitindo trabalhar com informações relacionadas ao pedido e ao cálculo de valores.

O projeto também possibilitou praticar a criação de layouts, organização dos componentes da tela e interação com o usuário utilizando **Java e XML**.

## 🎯 Objetivo

Desenvolver uma aplicação Android simples relacionada ao ambiente de um restaurante, colocando em prática conhecimentos de criação de interfaces, organização visual e interação com componentes da aplicação.

O projeto também teve como objetivo aprimorar a familiaridade com o **Android Studio**, Java e desenvolvimento de layouts utilizando XML.

## ⚙️ Funcionalidades

- 🍽️ Interface relacionada ao restaurante
- 📋 Seleção de itens do pedido
- 🔢 Cálculo de valores
- 💰 Exibição do valor da conta
- 🔘 Botões de interação
- 📱 Interface desenvolvida para dispositivos Android
- 🎨 Organização dos componentes da tela

## 🎨 Interface

A interface foi desenvolvida buscando manter uma aparência simples, organizada e relacionada ao tema de restaurante.

O projeto utiliza elementos visuais e componentes de interação para facilitar a utilização da aplicação.

Entre os principais elementos utilizados estão:

- 🍽️ Logo e identidade visual do restaurante
- 📋 Informações do pedido
- 🔢 Campos relacionados aos valores
- 💰 Área para o total da conta
- 🔘 Botões de interação
- 📱 Componentes de interface Android

## 💡 Aprendizados

O desenvolvimento do **Conta Restaurante** proporcionou uma experiência prática com a criação de interfaces para dispositivos móveis.

Durante o projeto, foram trabalhados conceitos de organização visual, posicionamento de componentes, interação com elementos da interface e implementação de funcionalidades relacionadas ao cálculo de valores.
