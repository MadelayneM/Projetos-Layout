# 📱 Projetos de Layout Android

Repositório criado para reunir projetos desenvolvidos durante a graduação em **Análise e Desenvolvimento de Sistemas (ADS)**, com foco na criação de interfaces e aplicações para dispositivos Android.

Os projetos foram desenvolvidos utilizando o **Android Studio**, colocando em prática conceitos de programação, criação de layouts, organização de componentes visuais e interação com o usuário.

## 📌 Sobre o projeto

Este repositório reúne diferentes atividades e projetos desenvolvidos durante os estudos de desenvolvimento mobile.

A proposta principal é praticar a criação de interfaces Android utilizando **Java e XML**, explorando diferentes tipos de aplicações e situações do dia a dia.

Atualmente, o repositório conta com dois projetos:

- 💰 **Projeto Poupança**
- 🍽️ **Conta Restaurante**

Cada projeto possui sua própria proposta, interface e funcionalidades.

## 💰 Projeto Poupança

Aplicativo desenvolvido para praticar a criação de uma interface relacionada ao controle e planejamento de uma poupança.

O projeto trabalha a organização de elementos visuais e a interação do usuário com a aplicação.

**Tecnologias:**
- ☕ Java
- 📱 Android Studio
- 🎨 XML

## 🍽️ Conta Restaurante

Aplicativo desenvolvido para praticar a criação de uma interface relacionada ao cálculo e organização de uma conta de restaurante.

O projeto utiliza elementos visuais e campos de interação para criar uma aplicação simples e funcional.

**Tecnologias:**
- ☕ Java
- 📱 Android Studio
- 🎨 XML

## 🛠️ Tecnologias utilizadas

- ☕ Java
- 📱 Android Studio
- 🎨 XML
- 🔧 Git
- 🐙 GitHub

## 📚 O que foi praticado

Durante o desenvolvimento dos projetos foram praticados conceitos como:

- Desenvolvimento de aplicações Android
- Criação de layouts utilizando XML
- Programação em Java
- Organização de componentes da interface
- Manipulação de elementos visuais
- Eventos de clique
- Interação com o usuário
- Organização de projetos no Android Studio
- Utilização do Git e GitHub para versionamento

## 🎯 Objetivo

O principal objetivo deste repositório é registrar a evolução dos conhecimentos em **desenvolvimento mobile**, reunindo projetos desenvolvidos ao longo da graduação e servindo como parte do portfólio acadêmico.

## 👩‍💻 Desenvolvimento

Projetos desenvolvidos durante a graduação em **Análise e Desenvolvimento de Sistemas (ADS)**, com foco no aprendizado e na aplicação prática de conceitos de desenvolvimento Android.

Este repositório poderá receber novos projetos e atividades conforme o avanço dos estudos.
